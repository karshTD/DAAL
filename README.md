# Design and Analysis of Algorithms (DAA) Lab

**Course Code:** T7909  
**Semester:** V  
**Academic Year:** 2026–27  
**Batch:** 2024–28  

---

## Course Overview

This lab focuses on designing, implementing, and analyzing algorithms using Divide and Conquer, Greedy, Dynamic Programming, and Backtracking strategies. Students learn to evaluate algorithm efficiency through complexity analysis and performance comparison.

---

## Topics Covered

| # | Experiment |
|---|------------|
| 1 | Linear and Binary Search (iterative and recursive) |
| 2 | Quick Sort (Divide and Conquer) |
| 3 | Merge Sort (Divide and Conquer) |
| 4 | Prim's and Kruskal's Algorithms (Minimum Spanning Tree) |
| 5 | Fractional Knapsack (Greedy Strategy) |
| 6 | Activity Selection (Greedy Strategy) |
| 7 | Bellman-Ford Algorithm (Single Source Shortest Path) |
| 8 | Travelling Salesperson Problem (Dynamic Programming) |
| 9 | N-Queens and Graph Coloring (Backtracking) |
| 10 | Hamiltonian Cycle (Backtracking and Branch & Bound) |

## Tools & Languages

- **Primary Language:** Python
- **Libraries:** time, random
- **Platforms:** VS Code, Jupyter Notebook, LeetCode

---

## Assignment Structure

Each lab experiment includes:

- Algorithm design (plain English or pseudocode)
- Full implementation with comments
- Comparison counters and execution time measurement
- Complexity analysis (best, average, worst cases)
- Industry-based case studies
- Related LeetCode problems for practice

---

## Key Learning Outcomes

- Analyze algorithm complexity using asymptotic notations
- Implement algorithms using various problem-solving strategies
- Compare algorithm performance across different input sizes
- Apply algorithmic thinking to real-world problems
